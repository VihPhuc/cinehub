## 3. Chi tiết

### 3.1 Điều hướng & state (App)

#### A1 — [P1] URL bị ghi đè khi hydrate; Back/Forward sinh entry rác

- **Vị trí:** `src/App.tsx:28-45` (state mặc định), `:131-203` (đọc URL), `:205-230` (ghi URL).
- **Bằng chứng:** State khởi tạo `home`/`null`; effect đọc URL chỉ `setState` đồng bộ hoặc fetch async.
  Effect ghi URL chạy ngay sau đó trong cùng commit với state mặc định → `newSearch=''` khác
  `?watch=...` → `pushState('/')`. Deep link `?info=` cũng bị đẩy `/` trước khi `setSelectedSlug`
  kịp render, rồi đẩy lại `?info=` ở lần render sau. Đóng modal set `selectedSlug=null` → push `/`
  (entry mới), nên Back mở lại modal vừa đóng.
- **Ảnh hưởng:** Link chia sẻ bị đổi ngay khi mở; history thành `[deep link, /, deep link]`;
  Back/Forward sai; nếu `getMovieDetail` fail thì mất deep link; `?page=` có thể bị ghi cả khi ở home.
- **Đề xuất:** Parse URL một lần trước render (`useState(() => parseUrl())` hoặc hook riêng);
  lần đồng bộ đầu dùng `replaceState`; chỉ `pushState` trong event handler (chọn tab/phim/trang);
  đóng modal/player bằng `history.back()` nếu entry hiện tại do chúng tạo, hoặc `replaceState`;
  popstate không `scrollTo({behavior:'smooth'})`; validate `TabId`, `page`.
- **Xác minh:** ✅ đọc code, logic chạy effect theo thứ tự khai báo.

### 3.2 API, cache, storage

#### B1 — [P1] Dedup in-flight dùng AbortSignal của caller đầu

- **Vị trí:** `src/services/api.ts:92-94`, `:96-119`, `:182-198`; `src/components/Navbar.tsx:128-142`.
- **Bằng chứng:** `inFlightRequests` trả promise được tạo với `externalSignal` của caller đầu.
  Caller sau nhận promise nhưng signal của nó không được gắn; caller đầu abort → fetch reject →
  catch `if (externalSignal?.aborted) return null` → **mọi caller** nhận `null`; `searchMovies`
  biến `null` thành danh sách rỗng.
- **Ảnh hưởng:** Navbar hủy request khi gõ tiếp có thể làm App hiện "không có kết quả";
  caller sau abort không có tác dụng, request vẫn chạy và setState muộn.
- **Đề xuất:** Cache promise "thuần" theo URL (không signal); mỗi caller `Promise.race` với signal riêng;
  hoặc ref-count, chỉ abort khi tất cả unsubscribe; trả kiểu `{ok, aborted, data}` thay vì `null`.
- **Xác minh:** ✅ đọc code.

### 3.3 Player, PWA, bảo mật
